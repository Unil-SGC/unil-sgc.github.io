Software ​

A succinct description and links to useful code repositories related to the activities of the Geocomputing Centre.

Centre repositories ​

Tools, templates and material shared by the community are hosted on the Unil-SGC GitHub organisation. The packaging repositories are the material of the packaging workshop.

geocomputing-coffeeMaterial of the informal geocomputing coffee meet-ups, starting with a Git and GitHub demo.Gitgit-demoDemo repository for a Git workflow.Gitpython-packagingMaterial of the packaging workshop, from a notebook to a package.Pythonjulia-packagingMaterial of the packaging workshop, from a notebook to a package.JuliaIceFlow.jlShallow-ice-approximation routines used as the packaging example.JuliaAGDA-RbookBook for the course "Advanced geospatial data analysis".Rsgc-assetsLogo and other assets of the Centre.Assets

Julia GPU development ​

Where the GPU work of the Centre and its partners lives, from the Julia GPU ecosystem to the GPU4GEO project and its organisations.

JuliaGPUThe Julia GPU ecosystem, with CUDA.jl, AMDGPU.jl, Metal.jl, oneAPI.jl and KernelAbstractions.jl, their documentation and tutorials.JuliaGPUGPU4GEOThe PASC project on GPU-based multi-physics solvers for geosciences in Julia.PASC projectPTsolversOrganisation of the pseudo-transient solvers, with applications and tutorials built on ParallelStencil.GitHubJuliaGeodynamicsOrganisation of Julia packages for geodynamics, such as GeoParams.jl and GeophysicalModelGenerator.jl.GitHub

Building blocks used across these projects:

ParallelStencil.jlHigh-level code for parallel high-performance stencil computations, deployable on both GPUs and CPUs.JuliaGPUImplicitGlobalGrid.jlAlmost trivial distributed parallelisation of stencil-based GPU and CPU applications on a regular staggered grid.JuliaGPUAMDGPU.jlAMD GPU (ROCm) programming in Julia.JuliaGPUKernelAbstractions.jlHeterogeneous programming in Julia.JuliaGPU
