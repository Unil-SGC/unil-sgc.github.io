# Software

A succinct description and links to useful code repositories related to the activities of the Geocomputing Centre.

## Centre repositories

Tools, templates and material shared by the community are hosted on the [Unil-SGC GitHub organisation](https://github.com/Unil-SGC):

- [geocomputing-coffee](https://github.com/Unil-SGC/geocomputing-coffee): material of the informal geocomputing coffee meet-ups, starting with a Git and GitHub demo.
- [git-demo](https://github.com/Unil-SGC/git-demo): demo repository for a Git workflow.
- [python-packaging](https://github.com/Unil-SGC/python-packaging) and [julia-packaging](https://github.com/Unil-SGC/julia-packaging): material of the [packaging workshop](/events/pkg-workshop), from a notebook to a package.
- [IceFlow.jl](https://github.com/Unil-SGC/IceFlow.jl): shallow-ice-approximation routines used as the packaging example.
- [AGDA-Rbook](https://github.com/Unil-SGC/AGDA-Rbook): book for the course "Advanced geospatial data analysis".
- [sgc-assets](https://github.com/Unil-SGC/sgc-assets): logo and other assets of the Centre.

## Julia GPU development

Ongoing development related to the [GPU4GEO](https://gpu4geo.org) PASC project is hosted on these organisations:

- [PTsolvers](https://github.com/PTsolvers) organisation
- [JuliaGeodynamics](https://github.com/JuliaGeodynamics) organisation

Building blocks:

- [ParallelStencil.jl](https://github.com/omlins/ParallelStencil.jl): package for writing high-level code for parallel high-performance stencil computations that can be deployed on both GPUs and CPUs.
- [ImplicitGlobalGrid.jl](https://github.com/eth-cscs/ImplicitGlobalGrid.jl): almost trivial distributed parallelisation of stencil-based GPU and CPU applications on a regular staggered grid.
- [AMDGPU.jl](https://github.com/JuliaGPU/AMDGPU.jl): AMD GPU (ROCm) programming in Julia.
- [KernelAbstractions.jl](https://github.com/JuliaGPU/KernelAbstractions.jl): heterogeneous programming in Julia.
