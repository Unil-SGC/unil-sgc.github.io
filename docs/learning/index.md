# Learning resources

Courses, tutorials and tools to get started with geocomputing. Some are free for the UNIL community, some are open to all.

## Courses and tutorials

- [Getting Started with Machine Learning](https://wp.unil.ch/dawn/getting-started-with-machine-learning/): a list of resources to help environmental scientists get started with machine learning. It includes tutorials with code, literature reviews, textbooks (often including code), and datasets that are already pre-processed for machine learning applications.

- [Hands-on introduction to Multiple Point Statistics](https://github.com/GAIA-UNIL/Short-course-MPS): an introduction to stochastic simulation using multiple point statistics, a modelling approach based on the use of training images with the aim of generating realistic heterogeneity characterising natural processes.

- [Solving PDEs in parallel on GPUs with Julia](https://pde-on-gpu.vaw.ethz.ch/): ETH's course 101-0250-00L on solving partial differential equations (PDEs) in parallel on graphical processing units (GPUs) with the Julia programming language.

- [FGSE geoinformatics and machine learning teaching materials](https://github.com/gse-unil): course materials and notebooks on geoinformatics and machine learning for Earth and environmental sciences.

- [EPFL on Coursera](https://www.coursera.org/epfl): a free platform where EPFL professors and others share plenty of high-level classes across many fields.

- [YouTube](https://www.youtube.com/): a less formal platform with a ton of very good resources; always check whether there are tutorials for your needs. A few examples: [Christian Kaiser](https://www.youtube.com/c/CKaiser) has a great channel for cartography (in French), the [Bro Code](https://www.youtube.com/c/BroCodez/videos) for Python tutorials, [The AI Guy](https://www.youtube.com/c/TheAIGuy/videos) for machine learning.

## Workshop and meet-up material

- [Packaging workshop (Python and Julia)](/events/pkg-workshop): from a Jupyter notebook to a package, with the [Python](https://github.com/Unil-SGC/python-packaging) and [Julia](https://github.com/Unil-SGC/julia-packaging) material.
- [Geocomputing coffee](https://github.com/Unil-SGC/geocomputing-coffee): Git, GitHub and remote development basics from the [first](/events/geocomp-coffee-1) and [second](/events/geocomp-coffee-2) meet-ups.
- [Advanced geospatial data analysis](https://github.com/Unil-SGC/AGDA-Rbook): the R book of the course.

## Open-source programming languages

- [Python](https://www.python.org/): a programming language that lets you work more quickly and integrate your systems more effectively.
- [R](https://www.r-project.org/): a free software environment for statistical computing and graphics.
- [Octave](https://octave.org/): a free alternative to [MATLAB](https://www.mathworks.com/products/matlab.html), useful for students who used that language during their studies.
- [Julia](https://julialang.org/): designed from the beginning for high performance.

For a more detailed comparison, read [R vs. Python vs. Julia](https://towardsdatascience.com/r-vs-python-vs-julia-90456a2bcbab).

## Web services for developers

- [Git](https://git-scm.com/): software that helps developers and data scientists store and manage their code and other text-based resources, track and control changes, and collaborate with others. Several web services host Git repositories and make them accessible: [GitHub](https://github.com/) is the best known, others are [GitLab](https://gitlab.com/explore), [Bitbucket](https://bitbucket.org/) and [Codeberg](https://codeberg.org/).

- [Jupyter](https://jupyter.org/): free software, open standards and web services for interactive computing across all programming languages.

- [Google Colaboratory](https://colab.research.google.com/): a hosted Jupyter notebook service that requires no setup, with free access to computing resources including GPUs.
